# 📝 To-Do List com Favoritos

Aplicação de lista de tarefas desenvolvida com React, TypeScript e Vite, incluindo sistema de favoritos e notificações.

## 🚀 Funcionalidades

- ✅ Adicionar, concluir e gerenciar tarefas
- ⭐ Marcar tarefas como favoritas
- 🔔 Sistema de notificações
- 🎨 Interface moderna e responsiva
- 🧭 Navegação entre páginas (Home e Favoritos)



## 📂 Estrutura do Projeto

- `/src/pages` - Páginas da aplicação (Home e Favoritos)
- `/src/components` - Componentes reutilizáveis
- `/src/context` - Context API para gerenciamento de estado
- `/src/types.ts` - Definições de tipos TypeScript
